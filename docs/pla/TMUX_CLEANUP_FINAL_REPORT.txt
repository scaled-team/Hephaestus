  2. Server didn't start as expected (likely Docker is serving it)
  3. Multiple retry attempts without knowing Docker was serving it
  4. Each retry left background processes/shells running
  5. Eventually accumulated multiple conflicting management scripts

Why This Was Wrong:
  • Docker Compose is the intended way to manage services
  • Frontend dev server should NOT be run locally - Docker handles it
  • Multiple management attempts caused resource conflict
  • Background shells consuming CPU/memory for nothing
